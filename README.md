# 🎮 Tic Tac Toe en React

Este es un proyecto de **Tic Tac Toe (Tres en Raya)** hecho con **React**


## 📦 **Instalación y Uso**
### **1️⃣ Clonar el Repositorio**
```bash
git clone https://github.com/FranciscoYuster/Tic-Tac-Toe
cd Tic-Tac-Toe
npm i
npm run dev
```
